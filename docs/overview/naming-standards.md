# Naming Standards

Based on structure from current employer, with my own changes.

| Object | Convention |
| --- | --- |
| Servers | Role + two digits |
| Clients | `CL` + two digits |
| User logon name | `first.last` |
| User principal name | `first.last@corp.meridian.lab` |
| Global security group (people) | `GG-<Dept>` |
| Domain local group (access) | `DL-<Resource>-<RW or R>` |
| GPO | `<Scope>-<Purpose>` |
| Scripts | `NN-verb-noun.ps1` |
